TrueCourse v0.6.1
Built: 2026-09-22

CRITICAL FIX: sw.js (the service worker) had a hardcoded cache name that
never changed across v0.2.0 through v0.6.0. Browsers only detect a new
service worker when its file bytes change — since sw.js was told
"unchanged, don't re-upload" every time, your browser likely kept
running the very first installed version regardless of how many times
app.js was replaced. This is almost certainly why Incubator (added in
v0.3.0) and other later features weren't showing up.

Fixed by bumping the cache name in sw.js. This one MUST be re-uploaded
along with app.js — going forward, sw.js will be bumped with every
version, no exceptions.

Verified with a real old-worker-to-new-worker lifecycle test (not just
a code read-through): confirmed the old cache is genuinely evicted and
the new one takes over after the swap.
